Smart Document Analyser

An AI-powered Smart Document Analyser developed using Python, Flask, Natural Language Processing (NLP), and Machine Learning techniques to automate document analysis and intelligent text processing.

Features
- Document text extraction
- Intelligent document classification
- NLP-based text analysis
- Keyword extraction
- User-friendly web interface
- Real-time document processing

Technologies Used
- Python
- Flask
- Machine Learning
- Natural Language Processing (NLP)
- Scikit-learn
- Pandas
- NumPy
- HTML/CSS

 How to Run

1. Clone the repository

git clone https://github.com/Mahima284/Smart-Document-Analyser.git

2. Install dependencies

pip install -r requirements.txt

3. Run the application

python app.py
